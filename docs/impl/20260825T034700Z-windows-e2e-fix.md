# Windows E2E 修复迭代

## 实现

- `src/main.zig`：增加 Windows 文件权限、PEB command line、环境块和 signal 选择的兼容分支。
- `src/core/shared/io.zig`：增加 Windows PID/HANDLE 转换、realpath 和目录 I/O 适配。
- `src/ui/ask_presentation.zig`、`src/ui/shell_runtime.zig`、`src/ui/terminal/terminal.zig`：补齐 Windows handle/raw mode/layout 的无 TTY 和 ConDrv 路径。
- `src/core/input/editor_state.zig`：修正 `copyForwards` 的等长切片契约。
- `src/core/session/session.zig`：旧 session 中未知工具结果枚举值按 `unknown` 诊断，不在 `@tagName` 处崩溃。
- `src/builtins/context.zig`：避开 Zig 0.16 Windows positional-read 问题，顺序读取 context 文件并继续执行大小、UTF-8 和文件 identity 检查。
- `build.zig`：Windows 链接 Winsock，并在 Debug 构建启用 error tracing。

## 结果

| 验证项 | 结果 |
| --- | --- |
| Windows Debug build | 通过 |
| Windows ReleaseFast build | 通过 |
| `fx status --json` | 退出码 0 |
| `fx doctor` | 退出码 0，0 fail；仅默认配置、状态目录和 gh 告警 |
| 本地 gateway SSE `fx ask` | 退出码 0，返回结构化 JSON |
| 全量 `zig build test` | 仍被 98 个 Zig 0.16 Windows 测试编译错误阻塞 |

全量测试失败主要集中在测试源码直接使用 POSIX `pollfd`、signal、socketpair、整数 fd、mode permissions 和 PID，而不是本次通过的主二进制路径。
